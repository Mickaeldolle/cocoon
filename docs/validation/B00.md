## Risques et limites

- La qualification locale ponctuelle ne remplace pas une mesure de qualité, latence, concurrence ou exposition réseau dans l’environnement cible.
- Le chemin Hermes n’est plus utilisé par le runtime MVP ; les éléments historiques restants ne sont pas des dépendances actives.
- Les tests SQLite ne remplacent pas les tests de concurrence et d’isolation PostgreSQL prévus en B01/B02 ; l’instance locale utilisée pour la migration n’est pas encore un environnement de test dédié.
- Le lint mobile reste bloqué par `apps/mobile/src/hooks/use-secret-gesture.ts` : React signale la lecture d’une ref et l’appel de `Date.now()` dans la création du `PanResponder`. Ce correctif doit être traité et validé séparément, car il concerne la surface d’accès secret et n’a pas été modifié.
- Aucun déploiement, bind LAN, changement de port ou migration d’une base personnelle n’a été effectué.

L’audit reproductible confirme maintenant l’état Git en utilisant une
configuration `safe.directory` locale à la commande, sans modifier la
configuration globale. Il confirme aussi Python, Node, uv, les lockfiles,
l’absence de secret suivi et l’ignorance de `.env`. `npm` reste absent du PATH
de ce processus ; le contrôle mobile de référence utilise donc directement le
runtime Node local lorsque nécessaire.
